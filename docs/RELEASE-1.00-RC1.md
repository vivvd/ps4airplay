# PS4 AirPlay 1.00-RC1 — основа 0.13

Установить **PS4-AirPlay-1.00-RC1.pkg** поверх текущего приложения при включённом HEN.
Открыть приложение, дождаться готовности. Название устройства AirPlay теперь **PS4 AirPlay**.
Компьютер для воспроизведения не нужен; iPhone и PS4 должны быть в одной локальной сети.

Добавлены:

- Прямая передача видео из плеера iPhone: HTTP(S) MP4/HLS через системный AvPlayer PS4,
  пауза и перемотка, обмен HLS-плейлистами через обратный канал AirPlay.
- Экран музыки в стиле Apple TV: обложка, название, исполнитель, альбом и прогресс,
  тёмный фон в цветах обложки. Фон и текст кэшируются.
- Исправление сохранения профилей через native Orbis I/O. Медиатракт музыки и
  повтора экрана взят из 0.13, прежние PKG/исходники 0.13 сохранены.

Проверить сначала **Apple Music**: выбрать PS4 AirPlay и переключить два трека
с разными обложками. Затем **Safari**: открыть видео, нажать AirPlay **в самом
плеере**, выбрать PS4 AirPlay, проверить звук, паузу и перемотку. Это отдельный
режим от «Повтора экрана». После этого проверить YouTube из приложения.

На геймпаде: SQUARE — диагностика, CROSS — пауза/продолжение прямого видео,
CIRCLE — остановка видео, OPTIONS — штатный выход. Музыкой управляет iPhone.

При проблеме: Safari → **http://IP-PS4:9080/** → **Скачать отчёт**.
IP виден внизу экрана. При зависании скачать до перезапуска; при краше открыть
приложение снова и сначала скачать отчёт. В отчёте есть direct_available,
direct_error/event, direct_video_frames, cover_images и metadata_packets.

Это **кандидат релиза**, а не подтверждённая стабильная версия: пройдены локальные
тесты с ASan/UBSan, реальное HTTP/FCUP/HLS-ядро, регрессии 0.13, 28 PKG-проверок,
извлечение runtime-модулей и повторная сборка из source ZIP. Новый AvPlayer,
метаданные/обложки и YouTube из текущего iOS-приложения ещё требуют проверки на PS4.
DRM-видео не поддерживается. Совместимость ссылок, HTTPS и кодеков зависит от
источника и системного плеера PS4; работа всех приложений не заявляется.

Полные исходники: **PS4-AirPlay-1.00-RC1-source.zip**. Превью экрана музыки в
validation/1.00-RC1 — локальная отрисовка с тестовой обложкой, не фотография PS4.
